# 品牌合作邮件管理工具

一个专为自媒体博主设计的品牌合作邮件管理工具，帮助你轻松整理和回复品牌方的合作邮件。

## ✨ 核心功能

### 📧 自动整理合作邮件
- 自动同步 163 邮箱中的品牌合作邮件
- 智能提取品牌名称、联系人、合作内容等关键信息
- 自动检测是否包含报价信息
- 清晰的表格式展示

### 🔍 筛选与导出
- 按时间范围筛选邮件（开始日期 - 结束日期）
- 按品牌名称搜索
- 一键导出为 Excel (.xlsx) 或 CSV 格式
- 导出文件包含完整的邮件信息

### 📝 模板管理
- 支持自定义邮件回复模板
- 内置 YES（接受合作）和 NO（拒绝合作）两种类型
- 支持变量替换：
  - `{{brand_name}}` - 品牌名称
  - `{{contact}}` - 联系人
  - `{{date}}` - 当前日期
  - `{{subject}}` - 原邮件主题

### 🚀 批量回复
- 支持选择多封邮件批量回复
- 选择模板后一键发送
- 自动使用正确的邮件线程（Reply-To）
- 发送进度实时反馈

## 🛠️ 技术栈

- **前端框架**: Next.js 14 + React 18
- **样式**: Tailwind CSS
- **邮件协议**: IMAP（接收）+ SMTP（发送）
- **导出功能**: xlsx 库
- **部署**: Vercel（推荐）

## 📋 前置要求

### 1. 开启 163 邮箱的 IMAP/SMTP 服务

1. 登录 [163 邮箱网页版](https://mail.163.com)
2. 点击顶部"设置" → "POP3/SMTP/IMAP"
3. 开启"IMAP/SMTP服务"
4. 系统会生成一个**授权码**，请务必保存好
5. 这个授权码就是登录时需要输入的"密码"（不是你的邮箱登录密码）

### 2. 系统要求

- Node.js 18.0 或更高版本
- npm 或 yarn 包管理器

## 🚀 快速开始

### 本地运行

1. **克隆项目**
```bash
git clone <your-repo-url>
cd brand_collab_claude
```

2. **安装依赖**
```bash
npm install
# 或
yarn install
```

3. **运行开发服务器**
```bash
npm run dev
# 或
yarn dev
```

4. **打开浏览器**
访问 [http://localhost:3000](http://localhost:3000)

5. **登录**
- 输入你的 163 邮箱地址（例如：`yourname@163.com`）
- 输入授权码（不是密码！）
- 点击"登录"

## 📖 使用指南

### 第一次使用

1. **登录**
   - 打开应用
   - 输入 163 邮箱和授权码
   - 点击"登录"

2. **同步邮件**
   - 登录成功后会进入仪表板
   - 点击"同步邮件"按钮
   - 等待同步完成（可能需要几秒到几十秒，取决于邮件数量）

3. **查看邮件**
   - 同步完成后，所有品牌合作邮件会显示在表格中
   - 表格包含：品牌名称、联系人、主题、时间、摘要、是否有报价

### 筛选邮件

1. **按时间筛选**
   - 选择"开始日期"和"结束日期"
   - 系统会自动筛选该时间范围内的邮件

2. **按品牌搜索**
   - 在"品牌名称"输入框中输入关键词
   - 系统会实时搜索匹配的邮件

### 导出邮件

1. 筛选出需要导出的邮件
2. 点击"导出 Excel"或"导出 CSV"按钮
3. 文件会自动下载到本地
4. 文件名格式：`品牌合作邮件_2025-11-21.xlsx`

### 管理模板

1. **查看模板**
   - 点击顶部"模板管理"按钮
   - 系统已内置 2 个默认模板

2. **添加新模板**
   - 在模板管理界面点击"添加新模板"
   - 填写模板名称、类型、主题、内容
   - 使用变量：`{{brand_name}}`、`{{contact}}`、`{{date}}`、`{{subject}}`
   - 点击"保存"

3. **编辑模板**
   - 在模板列表中点击"编辑"
   - 修改内容后点击"保存"

4. **删除模板**
   - 在模板列表中点击"删除"
   - 确认删除

### 回复邮件

#### 单个回复
1. 勾选要回复的邮件
2. 点击"批量接受"或"批量拒绝"（即使只选一封）
3. 选择模板
4. 预览邮件内容
5. 点击"确认发送"

#### 批量回复
1. 勾选多封邮件（可以点击表头的复选框全选）
2. 点击"批量接受 (N)"或"批量拒绝 (N)"
3. 选择模板
4. 预览第一封邮件的效果
5. 点击"确认发送"
6. 等待发送完成（会显示成功/失败数量）

## 🔒 安全说明

- **本地存储**：你的邮箱和授权码仅保存在浏览器的 localStorage 中
- **不上传服务器**：凭证不会上传到任何服务器（除了连接 163 邮箱时）
- **清除数据**：点击"退出登录"会清除本地保存的凭证
- **HTTPS**：部署到 Vercel 后自动启用 HTTPS 加密

## ⚠️ 常见问题

### 1. 登录失败："邮箱或授权码错误"

**原因**：
- 使用了邮箱密码而不是授权码
- 授权码输入错误
- 未开启 IMAP/SMTP 服务

**解决**：
1. 确认已在 163 邮箱设置中开启 IMAP/SMTP
2. 使用授权码，不是邮箱密码
3. 重新生成授权码并尝试

### 2. 同步邮件失败

**原因**：
- 网络连接问题
- 邮箱服务暂时不可用
- 授权码过期

**解决**：
1. 检查网络连接
2. 稍后重试
3. 重新生成授权码

### 3. 没有同步到合作邮件

**原因**：
- 邮件不包含合作关键词
- 邮件在其他文件夹（如垃圾箱）

**说明**：
系统会自动识别包含以下关键词的邮件：
- 中文：合作、广告、推广、投放、商务、品牌、营销、邀请、产品、试用、种草、带货
- 英文：collaboration, partnership, promotion, advertising, sponsored, campaign, influencer, creator

### 4. 发送邮件失败

**原因**：
- SMTP 连接问题
- 授权码失效
- 网络问题

**解决**：
1. 重新登录
2. 检查授权码是否有效
3. 检查网络连接

### 5. 部署到 Vercel 后无法使用

**注意**：
- Vercel 的 Serverless 函数有 10 秒超时限制
- 如果邮件数量过多，可能会超时
- 建议每次同步限制在 50-100 封邮件
